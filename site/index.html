Claude Code, in your pocket.

Start, watch, steer and approve Claude Code sessions on your own machines from your Android phone, over SSH. They are the same sessions claude agents shows on the computer, and they keep running when your phone sleeps. There are no servers and no accounts.

Your sessions keep working after you leave the desk.

Long sessions tend to stop and ask a question just after you’ve walked away. Tether sends that question to your phone, so you can answer it and the work carries on.

Approve from anywhere.
Choose Allow once, Always allow a rule, or Deny and tell Claude what to do instead. You can do it from the chat, from the home screen without opening the session, or straight from the notification.
A conversation, not a terminal
Replies stream in word by word and render as Markdown. Tool calls are quiet one-line rows that expand into diffs, command output and file previews.
Survives the phone
Sessions live in Claude Code’s own background service on your machine. If the phone sleeps, loses signal or closes the app, Tether picks up where it left off.
Everything a terminal can do
Stop a turn (Esc), cycle permission modes (Shift+Tab), switch models, run any slash command and attach images. Messages sent while Claude is busy are queued.
Plans and questions
Claude’s todo list becomes a pinned checklist with progress. Questions, and Claude Code’s own dialogs such as new MCP servers or folder trust, are answered with a tap.
Every session, on every machine
One list, like claude agents: running sessions, last week’s, and ones open in a terminal at the desk. Open any of them and reply; a stopped one wakes up under its own id.
Start sessions anywhere
Pick a machine, browse to a folder, choose a model and mode, and write the prompt. You can dictate it or attach images, and / brings up slash commands.
Built for mobile networks
SSH keepalives and instant reconnects when the network changes. An optional background service keeps links open so approval requests still arrive.

How it works

Your phone connects to your own machine over SSH, and a small helper script there talks to Claude Code’s own background service for you. Nothing runs anywhere else.

  1. Connect over SSH

    Tether connects to your machine using an SSH key it generated, or one you imported.

    user@workstation:22

  2. Install the helper

    It uploads a single Python script over SFTP. The script uses only the standard library.

    ~/.tether/bin/tether_helper.py

  3. Talk to Claude Code

    The helper starts, wakes and messages sessions through Claude Code’s daemon, the service behind claude agents, so the work keeps going if the connection drops.

    claude daemon

  4. Follow on the phone

    The app follows the session’s transcript from where it left off, streams the reply being written, and sends your messages, keys and approvals back.

    ~/.claude/projects/…/<session>.jsonl

What each machine needs

SSH
An SSH server your phone can reach, such as on your LAN or over Tailscale or WireGuard.
Claude Code
Version 2.1.286 or newer, installed and logged in, so claude agents works for that user.
Python 3.6+
python3 on Linux or macOS. There’s nothing to pip install.

Your machines, your keys

Tether has no backend. Your code, prompts and conversations stay on your machines and your phone.

  • Secrets encrypted at restPrivate keys, passphrases and passwords are encrypted with an AES-256-GCM key that never leaves the Android Keystore.
  • Host keys pinnedThe first connection asks you to trust the fingerprint. If the key changes later, you get a red warning, and trusting the new key takes a deliberate press-and-hold.
  • Optional app lockLock with a fingerprint, face or device PIN. It applies on launch and after a minute in the background.
  • No cloud backupsApp data is excluded from Android backup and device-to-device transfer.
  • Verified updatesUpdates come from GitHub Releases. The APK’s SHA-256 must match the release manifest, and Android asks you to confirm the install.

Privacy

Tether never collects device IDs, hostnames, IPs, usernames, paths, prompts, code or session content.

It sends anonymous, coarse usage events (such as app opened or session started) through Aptabase, an open-source analytics service. The events include the app version, OS version, locale and a random session id that rotates. Nothing is sent until you acknowledge a notice on Home, and one tap in Settings → Privacy turns it off. Builds without an analytics key, such as forks, send nothing.

Build it yourself

Tether is written in Kotlin with Jetpack Compose. You need JDK 17 and the Android SDK.

$ git clone https://github.com/iwm911/Tether.git && cd Tether
$ export ANDROID_HOME=~/Android/Sdk
$ ./gradlew :app:testDebugUnitTest :app:assembleRelease
# → app/build/outputs/apk/release/

Release builds are signed with your own key via keystore.properties. If you run a fork, point the in-app updater at your own releases with -PtetherUpdateRepo=owner/name.

The architecture and the Claude Code protocol notes are in docs/SPEC.md. To contribute, see CONTRIBUTING.md.
